Soma de A usando B e C

se A = 0
então processa B
senão (
   A := A - 1;
   C := C + 1
)

até B = 0
faça (
   B := B - 1;
   C := C + 1
)

1 ZER A 2 3      ; se A = 0 então processa B; senão transfere uma unidade de A para C
2 ZER B 7 5      ; se B = 0 então termina; senão transfere uma unidade de B para C
3 SUB A 4        ; A := A - 1
4 ADD C 1        ; C := C + 1
5 SUB B 6        ; B := B - 1
6 ADD C 2        ; C := C + 1
