Divisão de A por B usando C e D

até não ser possível retirar uma cópia completa de B de A
faça (
   retira uma cópia de B de A usando D;
   restaura B usando D;
   C := C + 1
)

1 ZER B 7 2      ; se B = 0 então restaura o divisor; senão continua retirando unidades de A e B
2 ZER A 10 3     ; se A = 0 antes de B então encerra; senão continua a subtração
3 SUB A 4        ; A := A - 1
4 SUB B 5        ; B := B - 1
5 ADD D 1        ; D := D + 1 (registra unidade retirada de B)

6 ADD B 7        ; B := B + 1 (restauração do divisor)
7 ZER D 9 8      ; se D = 0 então divisor restaurado; senão continua restaurando
8 SUB D 6        ; D := D - 1
9 ADD C 1        ; C := C + 1 (contabiliza uma subtração completa)
